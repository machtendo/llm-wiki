### Guidelines for Adding Playbooks

When creating a new playbook page:
1. Use `type: Playbook` in frontmatter
2. Include `trigger` section describing when to activate
3. Number steps sequentially for clarity
4. Link to relevant [entities](../entities/) and [computations](../computations/)
5. Set `stale_after` for time-sensitive procedures
